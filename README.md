## 🌟 Highlights & Features

- **Tactile Claymorphism Aesthetic**: Rich dark wine-red visual identity with multi-layered specular highlights, inner debossed lighting, and glowing accents.
- **Synthesized Web Audio Feedback**: Built-in zero-dependency Web Audio API sound effects (pops, clicks, feedback) that trigger on button clicks and card interaction.
- **Scroll-Driven Dynamic Animations**: Smooth viewport reveal animations, scroll progress indicators, and dynamic typewriter text cycles.
- **Comprehensive Project Showcase**: Full-stack web applications, real-time civic queueing engines, citizen registry systems, and autonomous robotics with interactive case study modals.
- **Resume & PDF Integration**: Direct one-click download for official resume credentials across hero, navigation bar, credentials card, and contact sections.
- **Direct Contacts**: Integrated communication deck with email copy clipboard, direct phone connectivity, and Facebook link.

---

## 🛠️ Technical Stack

- **Frontend**: React 19, Vite, Vanilla CSS Design System with Claymorphism tokens.
- **Icons & Visuals**: Lucide React, bespoke SVG logos for PHP, Python, JavaScript, C++, Arduino, PostgreSQL, MySQL, Cisco, and Networking.
- **Interactivity**: Canvas Confetti, Web Audio API Sound Synthesizer, IntersectionObserver scroll animations.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/darslabial/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
